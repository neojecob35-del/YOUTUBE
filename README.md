# Shorts Bot
Build: push this folder to a GitHub repo -> Actions tab -> "Build APK" -> download artifact `ShortsBot-debug-apk` -> unzip -> install app-debug.apk.
Or open in Android Studio and Run.
Use: open app -> enable accessibility service ("Shorts Bot") -> set AI URL/model -> START -> a Short must be on screen.
Note: 127.0.0.1 only works if opencodex runs on the same phone (e.g. Termux). Otherwise use your PC's LAN IP, e.g. http://192.168.1.5:10100/v1.
